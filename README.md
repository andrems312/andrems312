### 🚀 Projetos em destaque

#### 🔎 [DocuMind AI](https://github.com/andrems312/documind-ai)
Plataforma SaaS para **conversar com PDFs usando RAG**. As respostas vêm apenas de trechos recuperados dos seus documentos, **com citação da página** — e quando nada relevante é encontrado, o sistema avisa em vez de inventar.
> `Next.js 15` · `FastAPI` · `pgvector` · `Supabase` · `OpenRouter` · `Docker`
> Busca híbrida (vetorial + full-text com fusão RRF), chat em streaming e deploy documentado.

#### 📚 [Assistente de Estudos](https://github.com/andrems312/assistente-de-estudos)
Chatbot de estudos com interface web moderna, focado em perguntas de programação e tecnologia. A chave da API fica protegida no servidor.
> `Python` · `Flask` · `OpenRouter`

#### 📝 [Sistema de Cadastro de Participantes](https://github.com/andrems312/sistema-cadastro-participantes)
Sistema web para cadastrar, organizar e consultar informações de participantes por uma interface administrativa simples.
> `TypeScript`

#### 🏳️ [Que Bandeira é Essa?](https://github.com/andrems312/que-bandeira-e-essa)
Joguinho web em que você adivinha o país pela bandeira. Projeto leve e divertido de front-end.
> `HTML` · `CSS` · `JavaScript`
